NICEGOLD MON is a custom WhatsApp bot dashboard with a screenshot-inspired mobile glass interface.

## Dashboard

- NICEGOLD branded header
- Sign In button area
- WhatsApp linking instructions
- My Bot Sessions with 3-slot layout
- Connect New Bot section
- Website pairing-code flow
- Manage Bot section
- Redeem Code section
- Floating add button
- Mobile responsive glass/dark design

## Run

```bash
npm install
cp .env.example .env
npm start
```

Open `http://127.0.0.1:3000`.

Pairing uses the WhatsApp pairing-code flow. Enter a full number with country code and digits only.
